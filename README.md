# FitFlow Redesign

## Overview

FitFlow Redesign is a redesigned fitness and wellness application developed as part of the IT3060 Human Computer Interaction project.

The project focuses on improving the fitness experience through personalized workout plans, social interaction, nutrition tracking, and AI-supported features.

## Project Objectives

- Improve the overall user experience of FitFlow.
- Provide personalized workout plans.
- Support social sharing and community interaction.
- Support nutrition tracking.
- Integrate AI/ML capabilities.
- Provide a scalable and maintainable system architecture.
- Support mobile and web experiences.
